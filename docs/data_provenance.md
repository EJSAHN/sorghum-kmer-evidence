# Data provenance

The input data are derived from Sorghum Association Panel WGS reads in **ENA PRJEB50066 / ERP134618**. Original citation: Boatwright JL et al. (2022), *The Plant Journal* 111:888–904, [doi:10.1111/tpj.15853](https://doi.org/10.1111/tpj.15853). Four discovery accessions and eight previously unused accessions from the same study were selected from an eligible pool of 279 PI accessions. That pool required paired high- and low-nitrogen phenotype records in three years; it was not an arbitrary random subset of all 400 accessions. The deterministic accession ranking used identifiers rather than phenotype magnitudes. Eligibility data: [Mahamkali et al., Dryad 2026](https://doi.org/10.5061/dryad.3j9kd51w9).

`data/derived/input_manifest.json` records the original source file, original SHA256, curated file hash and byte size, and tabular row/column schema. The catalogue and signature CSVs are byte-identical copies of verified analysis inputs. `simulation/CODE25_summary.json` retains only the scientific completion status and simulation-scope fields used by the audit; operational paths and environment information were removed. All full synthetic strata remain in `simulation/analysis/performance_by_stratum.csv.gz`.

The public runner reconstructs the numerical comparisons from the underlying query, word-support and group-support tables. It does not independently rescan the original FASTQs. The source study has no genomic truth labels for these selected sequence states. Comparisons with exact-span evidence must not be reported as an empirical real-data false-positive rate.

`data/derived/representative_cases` contains **derived case exports**: a short FASTA, event table, four explanatory case records and file provenance. These excerpts came from audited retained-read evidence. They are not whole FASTQ files. The phased complementation strings are inferred read-supported strings; the other sequence examples retain their observed-read provenance and coordinates. Cases were selected for explanation rather than frequency estimation.

`data/provenance` retains the full 279-accession ranking, 12 selected accession records, 210-file ENA source manifest, 595 frozen anchor pairs, 1,190 canonical anchor patterns, 663 discovery sequence states and detailed method recovery in `SOURCE_DATA_AND_METHODS.json`. In that JSON, paths `data/<name>` denote files next to the JSON in this public mirror; the archival original is `06_provenance` in the companion manuscript package. No raw whole FASTQ files, phenotype tables, source VCFs or reference genomes are included.

The article is CC BY 4.0; its license does not automatically label the underlying FASTQs. [ENA/INSDC policy](https://ena-browser-docs.readthedocs.io/en/latest/about/policies.html) provides unrestricted access and redistribution of archived sequence records with appropriate source citation. Cite the original study and retain the provenance above when using these derived inputs. No new restriction on the original sequence records is asserted by this repository.

Reference context uses the pinned NCBI assembly [GCF_000003195.3, Sorghum_bicolor_NCBIv3](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_000003195.3/), not an inferred equivalence to another reference release. The detailed provenance lists the exact compressed-file MD5/SHA256 and the historical minimap2 2.31-r1302 command settings. This reference context is not sample-genotype validation.
